# Core Components

---

## Admin
- `ItemForm`: Create items (dresses)
- `TaskForm`: Create manual tasks
- `ItemList`, `TaskList`: Lists and deletes
- `QuoteList`: Quote history

--- 

## Worker
- `ClientForm`: Register client
- `ClientList`: View existing clients
- `BudgetForm`: Select items + tasks
- `BudgetSummary`: Display summary + PDF + save
