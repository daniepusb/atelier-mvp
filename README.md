# Atelier MVP 🧵
## 📝 Description 
**Atelier** is a web platform for clothing brands that allows clients to quote custom jobs. Admins and workers collaborate to upload garments, tasks, and clients, and generate PDF quotes.


## 🚀 Tech Stack
- **Frontend:** React + TypeScript + TailwindCSS
- **Backend:** Firebase Auth + Firestore (NoSQL)
- **Storage:** Firebase Storage
- **Hosting:** Firebase Hosting (coming soon)
- **Deployment:** Netlify https://zesty-heliotrope-901f5e.netlify.app/
- **Tests:** Vitest + Testing Library

## 👥 User Roles
- **admin:** manages items, tasks, users, and views all quotes for the brand.
- **worker:** registers clients and generates quotes.


## 🛠️  Quick Start
Create a `/.evn` file. You can copy from `.env.example` file

Run `npm install` to install dependencies
```sh
npm install
```
Run `npm run dev` to start the server.
```sh
npm run dev
```
